# ヒキヨミ方式 v2

## 原則

ヒキヨミは、暦上の事実をそのまま勝敗予測へ変換しません。まず複数方式で共通利用できる中間指標へ変換し、その後に表示用の「引き運」「台選び運」「流れ運」「冷静さ運」へ統合します。

## 中間指標

- activity: 行動開始のしやすさ
- judgment: 選択基準の安定
- continuity: 継続性
- adaptability: 変化への対応
- caution: 確認を増やす必要性
- impulseControl: 衝動抑制
- concentration: 集中の維持
- switching: 切替のしやすさ

## 現在のV2基盤

現段階では、以下だけを有効化しています。

1. 日付の六十干支
2. 日干・日支の構造
3. 生年月日と対象日の縮約数
4. 任意の出生時刻を十二支の時刻区分へ変換
5. ユーザー・対象日・秘密値による±2点以内の決定論的補正

暦の構造は公的資料に基づきますが、そこから中間指標へ何点動かすかはヒキヨミ独自規則です。伝統占術の普遍的事実として扱いません。

## 出生時刻

出生時刻は任意です。不明な場合は補正を付けず、減点もしません。分かる場合のみ時支を計算し、補助的な個人化へ使います。

## 追跡可能性

各寄与は以下を保持します。

- ruleId
- kind
- metric
- delta
- basis
- sourceIds

これにより、どの規則がどの指標を何点動かしたかを後から逆引きできます。
