# ヒキヨミ方式 v3

## 占いとしての位置付け

占いは、未知の事柄について、暦・数・象徴・伝統的規則などを解釈し、見方や行動のきっかけを提示する文化的実践です。診断、助言、予測など多様な形があります。

ただし、占星術や暦占いによってスロットの設定・当選・勝敗を高い確率で予測できるという科学的根拠は確認されていません。ヒキヨミは、勝率予測ではなく、次の3層を明確に分けます。

1. **検証可能な暦計算**: 日付の干支、十干、十二支、五行、陰陽
2. **占い上の象徴変換**: 点数、ラッキー末尾、スロットタイプ、メーカー候補
3. **実用的な安全指針**: 時間・予算の事前設定、休憩、損失回収目的の追加を避ける

## 精度の定義

ヒキヨミで高められる「精度」は、勝率ではありません。

- 暦計算が正しいこと
- 同じ利用者・同じ日なら同じ結果になること
- 表示内容が内部計算と一致すること
- AIが存在しない理由や出来事を創作しないこと
- 伝統部分と独自部分を混同しないこと
- 行動指針が安全性の知見と矛盾しないこと

## 入力

- 生年月日: 必須
- 出生時刻: 任意

出生時刻を覚えていない利用者に調査を要求しません。未登録でも利用でき、点数上の一律減点はありません。分かる場合だけ時支による小幅な補助調整を使います。

## 暦・数の基盤

現在使用する事実データ:

1. 日付の六十干支
2. 十干・十二支の五行と陰陽
3. 生年月日と対象日の縮約数
4. 任意の出生時刻を十二支の時刻区分へ変換

暦構造は公的資料を参照します。暦の事実からスロット表示へ変換する規則はヒキヨミ独自方式であり、伝統占術の普遍的事実として扱いません。

## 点数

利用者向けに表示する点数は次の2つです。

- 総合スロ運
- 引き運

「台選び運」「流れ運」「冷静さ運」は、定義が曖昧で本人の能力評価と誤解されるため表示しません。内部指標は、表示点数と象徴候補を安定して生成するためだけに使います。

ユーザー・日付・秘密値によるランダム風の補正は最終点数から除外しました。最終結果は暦・数の寄与から決定します。

## おすすめスロットタイプ

対象日の五行と陰陽を、ヒキヨミ独自の象徴変換表で次の分類へ置き換えます。

- Aタイプ
- AT機
- スマスロAT機
- メダルAT機

これは伝統占術に存在するスロット分類ではありません。五行・陰陽の象徴を現代の遊技分類へ翻訳した娯楽上の候補であり、設定・勝率・期待値を示しません。

## 相性メーカー

メーカー2社は、生年月日、対象日、暦・数の確定値から決定論的に選びます。同一人物・同一日は固定です。

メーカー名は占い上の候補であり、各社との提携、協賛、推奨、公式認定を意味しません。

## ラッキー要素

- ラッキー末尾: 表示する
- 意識する数字: 利用方法が不明確で末尾と重複するため非表示
- ラッキーカラー
- ラッキーアイテム
- ラッキータイム

ラッキー要素は、同条件で迷ったときの娯楽上の目印です。遊技継続や追加支出の根拠にはしません。

## 行動指針

「今日の立ち回りテーマ」と「今日の注意ポイント」は、勝敗予測ではなく安全な遊技行動へ限定します。

- 終了時刻を事前に決める
- 使用上限を事前に決める
- 一定時間ごとに休憩する
- 取り返す目的で上限を増やさない
- 見送る選択を残す

## 鑑定文

生成AIは使用しません。鑑定文は、コードで確定した次の項目だけを定型文へ組み立てます。

- おすすめスロットタイプ
- 相性メーカー
- ラッキー末尾
- 立ち回りテーマ
- 注意ポイント

これにより、入力にない天体、出来事、性格、技量、店舗状況を文章が創作する余地をなくします。

## 根拠表示

内部では、規則ID、参照資料ID、暦要素、寄与を保存します。一方、利用者向けの「鑑定の根拠」「参考度」「一致度」は、理解しにくく勝率のように誤解されるため結果画面から外します。
